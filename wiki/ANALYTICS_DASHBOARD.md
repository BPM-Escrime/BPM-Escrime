# Analytics Dashboard Guide

## Overview

L'Analytics Dashboard de BPM - Escrime offre aux entraîneurs et organisateurs une vue complète en temps réel des performances et statistiques des compétitions.

## Fonctionnalités principales

### 📊 **Métriques en temps réel**
- **Nombre total de tireurs** - Suivi des participants
- **Matchs terminés** - Progression de la compétition
- **Durée moyenne des matchs** - Performance temporelle
- **Dernière mise à jour** - Fraîcheur des données

### 🏆 **Classement des performeurs**
- **Top 5 des tireurs** - Basé sur le taux de victoire
- **Statistiques individuelles** - Victoires, moyenne des scores, touches données/reçues
- **Séries actuelles** - Victoires consécutives
- **Forme récente** - Excellent/Good/Average/Poor basé sur les 5 derniers matchs

### 📈 **Statistiques par arme**
- **Matchs totaux** - Volume par type d'arme
- **Marge de victoire moyenne** - Domination dans les matchs
- **Match le plus intense** - Plus grand nombre de touches

### 📋 **Progression des poules**
- **Pourcentage d'achèvement** - Avancement visuel
- **Temps restant estimé** - Prédictions de fin
- **État en temps réel** - Mises à jour automatiques

## Configuration

### 🔄 **Actualisation automatique**
- **Cochez "Auto-refresh"** pour les mises à jour toutes les 5 secondes
- **Mode "Live"** : Données des 5 dernières minutes
- **Mode "Last 30 min"** : Vue d'ensemble récente
- **Mode "All time"** : Historique complet

### 🎯 **Filtres temporels**
Sélectionnez la période d'analyse selon vos besoins :
- **Live** : Pour suivre en direct
- **Last 30 minutes** : Vue à moyen terme
- **All time** : Statistiques complètes

## Utilisation pratique

### Pour les entraîneurs
1. **Surveillez la forme** des tireurs en temps réel
2. **Identifiez les tendances** de performance
3. **Prenez des décisions** basées sur les données
4. **Comparez les tireurs** pour les stratégies

### Pour les organisateurs
1. **Suivez le progrès** de la compétition
2. **Identifiez les retards** ou problèmes
3. **Anticipez la durée** totale
4. **Optimisez le flux** des matchs

## Indicateurs visuels

### 🎨 **Codes de couleur**
- 🟢 **Excellent** : Forme exceptionnelle (>80% victoires)
- 🔵 **Good** : Bonne performance (60-80%)
- 🟡 **Average** : Performance moyenne (40-60%)
- 🔴 **Poor** : Forme faible (<40%)

### 📊 **Interprétation**
- **Taux de victoire** : Ratio V/M, indicateur clé de performance
- **Indice (TD-TR)** : Différence touches données/reçues
- **Forme récente** : Tendance sur les derniers matchs

## Conseils d'utilisation

### 📈 **Analyse des tendances**
- Comparez la forme récente au taux global
- Identifiez les tireurs en progression
- Surveillez les chutes de performance

### ⏰ **Gestion du temps**
- Utilisez les données de durée pour planifier
- Identifiez les matchs qui durent anormalement longtemps
- Anticipez les temps de fin de poules

### 🎯 **Optimisation**
- Repérez les inégalités dans les poules
- Ajustez les stratégies d'entraînement
- Préparez les tireurs selon leurs forces/faiblesses

## Export et partage

Les données du dashboard peuvent être :
- **Exportées en PDF** pour les rapports
- **Copiées** pour les présentations
- **Suivies en direct** pendant la compétition
